# E-POCH IT company website

A static, dependency-free website built with HTML, CSS, and vanilla JavaScript. It has no build step, package installation, backend, or runtime CSS framework.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server:

```sh
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Publish with GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and the root folder, then save. The site entry point is `index.html`.

Contact buttons open the visitor’s email or phone app. Navigation, package details, and animation run in the browser; there is no server-side application.
